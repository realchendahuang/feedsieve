# FeedSieve Roadmap

## v0.1 — 先把个人过滤做对

目标：不依赖后端、不依赖 AI，也能明显改善 X 浏览体验。

- 浏览器扩展基础架构
- X Home Timeline
- Replies
- 关键词 / 正则
- 个人黑名单 / 白名单
- 重复内容识别
- 一键“抬走这个账号”
- “我偏要看”恢复
- 本地统计

成功标准：

> 用户安装后 5 分钟内能明显看到垃圾减少。

## v0.2 — 社区共创

目标：让一个用户发现的垃圾账号，帮助更多用户少看一次。

- Community Report API
- Community Candidate Pool
- Community Score
- Reporter Trust
- 反向恢复票
- Community Filter Packs
- 版本化社区过滤快照
- 一键启用社区清单
- 本地缓存与离线过滤

成功标准：

> 新用户即使没有配置任何规则，也能因为社区清单立即获得明显过滤效果。

## v0.3 — AI 会认

目标：处理规则和社区信号无法可靠判断的模糊内容。

- OpenAI-compatible API
- 自定义 Endpoint / Model
- AI 垃圾分类
- Engagement bait
- AI slop
- 营销 / 引流
- 自然语言过滤偏好
- AI Decision Cache

原则：

> AI 是第三层过滤，不是每条推文的第一道门。

## v0.4 — 会整活

目标：让产品自己传播。

- 今日战报
- 分享卡片
- 随机梗文案
- 类型统计
- 社区贡献统计
- 一键分享到 X

成功标准：

> 用户愿意主动把过滤战报发到 X。

## v0.5 — 会进化

- 社区 Filter Pack 生态
- 规则导入 / 导出
- 多语言
- Firefox
- Safari 评估
- 本地模型
- Developer Filter API / SDK
- 更多信息流 Adapter
