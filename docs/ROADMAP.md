# FeedSieve Roadmap

## v0.1 — 能滤

目标：不依赖 AI，也能明显改善 X 浏览体验。

- 浏览器扩展基础架构
- X Home Timeline
- Replies
- 关键词 / 正则
- 黑名单 / 白名单
- 重复内容
- 手动“抬走”
- 手动恢复
- 本地统计

成功标准：

> 用户安装后 5 分钟内能明显看到垃圾减少。

## v0.2 — 会认

目标：加入可选 AI。

- OpenAI-compatible API
- 自定义 Endpoint / Model
- AI 垃圾分类
- Engagement bait
- AI slop
- 营销 / 引流
- 自然语言过滤偏好
- 误判反馈

## v0.3 — 会整活

目标：让产品自己传播。

- 今日战报
- 分享卡片
- 随机梗文案
- 类型统计
- 一键分享到 X

成功标准：

> 用户愿意主动把过滤战报发到 X。

## v0.4 — 会进化

- Filter Pack
- 社区规则
- 导入 / 导出
- 多语言
- Firefox
- Safari 评估
- 本地模型
- Developer Filter API
