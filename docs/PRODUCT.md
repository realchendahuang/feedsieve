# FeedSieve 产品说明

## 一句话

福滤娃 FeedSieve 是一个 X 赛博清洁工：在垃圾信息进入你的注意力之前，把它抬走。

## 用户问题

用户真正厌烦的通常不是“某一条垃圾推文”，而是重复出现的垃圾模式：

- 同一批机器人在热门推文下刷相似回复
- 模板化 AI 回复占满评论区
- 色情、灰产和 Telegram 引流
- 复制粘贴营销
- 无意义互动钓鱼
- 重复观点与内容农场
- 某些用户明确不想看到的关键词、账号或话术

传统屏蔽主要针对账号。FeedSieve 更进一步，过滤“内容模式”。

## MVP 用户路径

1. 用户安装浏览器扩展。
2. 打开 X。
3. FeedSieve 在页面中识别推文 / 回复。
4. 本地规则先判断。
5. 明显垃圾直接隐藏。
6. 模糊内容按用户设置进入 AI 判断。
7. 被隐藏内容保留一个轻量占位入口。
8. 用户可以选择“我偏要看”。
9. 用户可以将误判内容标记为“这条还能抢救”。
10. 所有结果进入本地统计，用于“今日战报”。

## 首版必须有

### Filtering

- 关键词
- 正则
- 账号黑名单
- 账号白名单
- 重复文本识别
- 复制模板识别
- 用户手动隐藏
- 可恢复

### UX

过滤必须尽量无感。

页面不应该因为 FeedSieve 出现明显跳动；垃圾内容最好在进入视野前完成折叠。

### Statistics

最少统计：

- 扫描总数
- 隐藏总数
- 按类型数量
- 手动恢复数
- 手动黑名单数

## 首版不急着做

- 完整第三方 X 客户端
- 云端账号系统
- 社交网络
- 大型后端
- 强依赖付费 AI
- 自动替用户举报账号
- 复杂推荐算法

## AI 策略

AI 不应该成为首层过滤器。

合理链路：

`DOM -> Feature Extraction -> Local Rules -> AI Fallback -> Action`

优点：

- 减少 Token 成本
- 减少延迟
- 减少隐私暴露
- 避免 API 不可用时产品失效

## 今日战报为什么重要

它同时承担三个作用：

1. 用户价值证明：今天到底替我过滤了多少垃圾。
2. 情绪价值：让枯燥统计变成梗。
3. 产品传播：卡片天然适合发到 X。

这不是一个附属功能，应当进入早期 Roadmap。
