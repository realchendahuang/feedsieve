# 弹窗与推文徽章重构（2026-10-30）

上一版只换了配色和字体，结构和交互没动。这一版按「用户来弹窗做什么」重排。

## 1. 现状问题

用 Ego Lite 在 520px 和 760px 宽度下截图核对过：

| 位置          | 问题                                                                                                         |
| ------------- | ------------------------------------------------------------------------------------------------------------ |
| 时间线推文    | 量级胶囊 108px、流速胶囊 75px，作者名被挤成「陈.」，handle 只剩「@.」                                        |
| 帖子详情页    | 流速胶囊塞进「推广 / Grok / …」按钮组，作者名列被压窄，handle 变成「@r…」                                    |
| 弹窗 340px 宽 | 本页简报四个数字重叠（「312/h41」）；名单页四个 tab 断成「社/区」「白名/单」；热帖的量级胶囊掉到第二行       |
| 弹窗结构      | 五个栏目里，关键词、名单是低频配置，却和高频的洞察、清理平级；名单页把 4053 个社区账号逐条列出，没人会逐条看 |

## 2. 推文徽章

**原则：作者的数据挂在作者旁边，帖子的数据挂在帖子的数据旁边。**

| 徽章 | 位置                                                        | 内容                                                                           |
| ---- | ----------------------------------------------------------- | ------------------------------------------------------------------------------ |
| 量级 | @handle 那一行末尾                                          | 只保留「图标 + 粉丝数」，例如 `☆ 12.8K`。档位名（MICRO）和中文名都移到悬停卡片 |
| 流速 | 时间线和详情页都在右上角，按钮组（推广 / Grok / …）的最前面 | `↗ 266/h`。破圈倍数 `×5.9` 移到悬停卡片                                        |

流速曾经在详情页挂到「6,511 查看」后面，用户要在两个地方找同一个数，已改回统一放在右上角。时间线也试过挂到动作栏的浏览数旁边，实测每格只有约 102px，`↗ 2.6K/h` 会压到收藏按钮上，放弃。

**窄屏退化**：`ResizeObserver` 按推文 `article` 的宽度写 `data-fs-size`，样式据此收起内容。不测量、也不改 X 自己元素的尺寸。

| 推文宽度            | 量级          | 时间线流速                             |
| ------------------- | ------------- | -------------------------------------- |
| ≥ 560px（桌面常规） | 图标 + 粉丝数 | 图标 + 数字                            |
| 470–560px           | 图标 + 粉丝数 | 图标 + 数字，内边距收紧                |
| < 470px             | 只有图标      | 平稳的绿色流速隐藏；正在火的只显示数字 |

520px 窗口实测：作者名「陈大黄」和 handle「@realchendahuang」完整显示（改前是「陈.」「@.」）。

## 3. 弹窗

### 3.1 栏目：五个变三个

| 栏目             | 回答的问题                               | 内容                                                                 |
| ---------------- | ---------------------------------------- | -------------------------------------------------------------------- |
| **热帖**（默认） | 这一页什么在火、回复谁划算               | 一行三项数据（帖子 / 在火 / 中位流速）、热度与回复机会切换、帖子列表 |
| **清理**         | 这一页有哪些垃圾、社区名单还剩多少没拉黑 | 本页标黄账号列表与批量拉黑；社区黑名单一行入口                       |
| **设置**         | 改规则、查记录                           | 分组列表，低频内容点进二级页                                         |

删掉的栏目和去向：

- **关键词** → 设置 › 关键词（二级页）。
- **名单** 拆开：社区黑名单 → 清理页底部一行（数量 + 全部拉黑 + 官网公示链接），不再逐条列 4000 多个账号；拉黑记录、白名单、关注保护 → 设置里各自的二级页。
- 刊头日期删除，它不帮助任何操作。侧边栏按钮只留图标。
- 清理栏目的角标只显示本页待处理数；社区名单的「99」不再常驻，它不是需要马上处理的事。

### 3.2 热帖

- 简报从「四格大数字 + 量级分布条 + 破圈最高」缩成一行三个数。量级分布和破圈最高不指向任何操作，删除。
- 每条帖子三行：作者行（名字、量级、发布时间）、正文两行、一行指标。
- 指标行随排序变化：热度看「流速、破圈、浏览」，回复机会看「还能新增的浏览、已有回复、剩余时间」，不再两行叠加。
- 爆帖指数的数字不再列出（排名本身就是顺序），留在推文悬停卡片里。

### 3.3 清理

- 每个账号：第一行勾选框、@handle、名字、「误标」「移除」两个按钮；第二行类别和命中理由；下面两行正文。
- 底部固定一个主按钮「拉黑 N 个」。
- 社区黑名单只占一行：`社区黑名单 · 4053 个未拉黑 [全部拉黑] ↗`。队列进行中时，进度面板显示在触发它的位置。

### 3.4 设置

Notion 设置页式的分组列表，每行左边是名称，右边是控件或数量加「›」：

- **过滤**：页面标黄、识别强度、关键词 ›、拉黑记录 ›、白名单 ›、关注保护 ›、每日上限
- **显示**：流速与量级、界面语言
- **数据**：仅本地运行、社区数据同步、备份与迁移
- **关于**：GitHub、官网

二级页顶部是「‹ 设置」返回和页面标题。

### 3.5 宽度

弹窗从 560px 改为 420px，侧边栏可以拖到 300px。所有行在 300px 下不断字、不重叠：长名字截断，按钮不换行，数字用等宽数字。

## 4. 不变的部分

- 所有数据接口、存储键、内容脚本消息不变。
- 拉黑安全队列、额度、官方暂停开关的逻辑不变，只换展示位置。
- 旧链接参数兼容：`?view=lists&list=blocked` 打开设置 › 拉黑记录，`?view=keywords` 打开设置 › 关键词。

## 5. 配色规则

上一版量级用了六种颜色（灰、青绿、蓝、紫、橙、金），流速用绿和红。两者都是带底色的胶囊，青绿和流速的绿相近，橙金和流速的红相近。用户分不清一个颜色说的是「这个人很大」还是「这条帖子很火」。

现在每种颜色只表达一件事：

| 颜色    | 含义                       | 用在哪里                                     |
| ------- | -------------------------- | -------------------------------------------- |
| 灰      | 身份与元数据，不需要注意   | 量级（图标 + 粉丝数）、时间、浏览数          |
| 绿 → 红 | 热度，页面上唯一的彩色刻度 | 流速                                         |
| 黄      | 需要你处理                 | 标黄的垃圾账号、类别标签、「清理」栏目的角标 |
| 蓝      | 控件                       | 开关、输入框焦点                             |

具体规则：

- **量级不上色**。它是作者的静态属性，用 X 自己的元数据写法接在后面：`@handle · 8小时 · ☆ 12.8K`，颜色继承那一行的次要文字色，亮暗主题自动跟随。六档只靠图标区分（嫩芽 → 皇冠），档位名在悬停卡片里。
- **只有流速会有底色，而且越热越醒目**：平稳只有绿字；≥ 1000/h 红字加浅红底；≥ 1 万/h 实心红底。一屏里出现底色的地方，就是值得看的帖子。
- **红色只留给热度**。「清理」角标原来是红色，现在改成和标黄框同一个黄色，表示「待处理」而不是「火了」。
- 弹窗里的热帖列表用同一套规则：量级是灰字，流速按同样三档上色。

## 6. 标黄与拉黑

标黄属于配色规则里的「黄 = 需要你处理」：

- 推文不再整圈描黄框，改成左侧一条 3px 黄线加极浅的黄底，和 X 的时间线融在一起。
- 推文下方一行与正文左对齐：`[盾牌] 命中官方规则：骚货 · 正文 …… [拉黑] 误标？`。理由用 X 的次要文字色，只有盾牌图标和「拉黑」按钮是黄色。字体、字号跟 X 一致。
- 没被标黄的推文，动作栏末尾原来是「拉黑」两个字，现在是和 X 同款的图标按钮（用户叉），悬停变黄；拉黑中图标闪烁，成功变成对勾，失败短暂显示错误码。

## 7. 字体与热帖可读性

- 弹窗全部改用系统默认界面字体（和 X 网页版一样），去掉衬线字体。正文 14px，热帖正文 15px / 1.5 行高，与 X 一致。
- 刊头改成两层：上面是商标行（图标 + 主名 + 另一种语言的副名，中文界面是「福滤娃 FeedSieve」，英文界面是「FeedSieve 福滤娃」），下面是纯文字标签。
- 热帖条目就是一条 X 推文，用户不用重新学：
  - 左边 40px 圆头像（来自 GraphQL 的 `avatar.image_url`）；右边作者行「名字 蓝标 @handle · 2小时 · ☆ 12.8K」，流速在右上角，和推文上的位置一致。窄宽度下先截 handle、再截名字；侧边栏窄到正文列不足 260px 时收起量级。
  - 正文完整显示，保留换行，最多 12 行；末尾作为图片 / 视频占位的 t.co 链接去掉。长帖（note tweet）解析全文，桥接层正文上限从 280 字提高到 1000 字。有图片或视频时显示第一张图或封面。
  - 底部是 X 同款动作栏：回复、转发、喜欢、浏览、收藏（收藏和 X 时间线一样只有图标）。
  - 排名数字、预计浏览、破圈倍数这些额外信息不放在卡片上；只有「回复机会」排序时多一行理由（还能新增的浏览、已有回复、剩余时间）。
  - 头像和图片只加载 `pbs.twimg.com` 的地址，桥接层和弹窗各校验一次。
- 点开热帖：帖子还在当前页面上就滚过去高亮；不在就在后台标签页打开（紧挨当前标签页，不切过去）。当前页面不切走，热帖列表就不会变空，可以连续打开多条。点过的帖子变淡。
- 侧边栏顶部 Chrome 已经显示了图标和「FeedSieve」，侧边栏里不再显示自己的商标行；弹窗里保留。
- 清理列表的「误标」「移除」挪到第一行右侧，正文用满整列宽度，最多 4 行。
