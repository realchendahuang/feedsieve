## 1. X 现在怎么排 For You

**打分**：Phoenix（基于 Grok 的 transformer）预测「这个用户对这条帖子做各种动作的概率」，再加权求和：

```text
分数 = Σ 权重 × P(动作)
```

权重（`home-mixer/params/param.rs`）：

| 动作         | 权重                    | 动作     | 权重   |
| ------------ | ----------------------- | -------- | ------ |
| 复制链接分享 | 20                      | 点赞     | 0.708  |
| 回复         | 5（互关的人回复再 +15） | 点击     | 0.274  |
| 引用         | 5                       | 打开链接 | 0.2    |
| 私信分享     | 5                       | 不感兴趣 | −53.07 |
| 关注作者     | 4                       | 静音作者 | −58.8  |
| 分享         | 2.118                   | 拉黑作者 | −31.2  |
| 转发         | 1                       | 举报     | −234   |

注：2026-11-05 起 Phoenix 启用了 `DENSE_WITH_LONG_DWELL_HOME_EXCURSION`（`EnableHomeExcursionScores = true`），信息流连续停留权重从 `0.006` 升至 `0.0075`（`ContDwellTimeWeight`）、详情停留调至 `0.385`、`VideoOpenWeight` 归零；并新增预测「视频续看时长」「进主页停留时长」及 `PostVideoWeight` / `GrokAnalyzeWeight`（默认权重暂为 0）。`ShareViaCopyLinkWeight` 曾在 11-13 临时归零，11-18 已恢复 `20`。

注意：权重乘的是**预测概率**，不是实际次数。X 在代码注释里专门说明：不能理解成「1 次举报抵 468 个赞」。但相对重要性可以借用：**回复、引用、转发到私信/复制链接，比点赞值钱得多**。

**之后的调整**（`xai-value-model/scoring.rs`、`vm-ranker/params.rs`、`home-mixer/filters/`）：

- 非关注者看到的帖子 ×0.75（OON 折扣）。所以浏览远超粉丝，说明推荐系统在主动分发。
- 同一作者在一屏里的第 2、3 条帖子逐条打折（衰减 0.5，下限 0.25）；`vm-ranker` 并上线了基于 Semantic ID 与 Embedding 的 DPP 滑动窗口多样性重排（`DppEnabled = true, DppTheta = 0.65`）。
- 超过 48 小时的帖子直接过滤（`MAX_POST_AGE`）。
- 针对新用户/回流用户新增了赞播比门槛参数（`NewUserMinEngagementFilterUseRatio = true, NewUserMinEngagementThreshold = 0.004`，即非关注者候选要求点赞/浏览 ≥ 0.4%，当前总开关默认灰度控制）。
- `xai-value-model` 已合入实验性乘法模式（`ValueModelMode = "multiplicative"`，把不划走惩罚 `not_dwelled`、互动项与停留时长相乘）以及关注内/破圈 `ClassFactors` 分离缩放，默认仍为 `"weighted"` 线性加权。

**两条对创作者最重要的机制**：

1. **全站热门帖子池**（`home-mixer/util/popular_posts.rs`）。每 60 秒刷新一次，按「预计 24 小时浏览」选 500 条（每个作者最多 5 条），作为非关注者的候选来源。公式：
   ```text
   λ = ln2 / 8h
   预计 24h 浏览 = 当前浏览 × (1 − e^(−24λ)) / (1 − e^(−λ·max(帖子年龄, 0.5h)))
   ```
   这是 X 自己对「爆款」的定义。
2. **冷启动扶持**（`home-mixer/scorers/author_cold_start.rs`）。粉丝 ≤ 5 万的作者、**非回复且非转发**的帖子，在发出 2 小时内、首页曝光不足 200 时，会通过 Thompson Sampling 被插进少量推荐位（15–16 位）试水。

## 2. 我们据此做的调整

| 项                 | 之前                                        | 现在                                                                                       | 依据                                                             |
| ------------------ | ------------------------------------------- | ------------------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| 流速               | 总浏览 ÷ 帖子年龄（全程平均）               | 衰减模型推算「此刻」速度；多点滑窗取 10–60 分钟差分，久未刷新按观测时刻起算衰减到 `now`    | 热门帖子池的 8 小时半衰期模型；防止跨 1 小时边界塌缩与过期帖冻结 |
| 流速有效期         | 72 小时                                     | 48 小时                                                                                    | X 不推荐 48 小时以上的帖子                                       |
| 爆帖指数           | 流速 + 互动率 + 转赞比 + 藏赞比（照搬竞品） | 预计 24h 浏览 45 分 + 小样本平滑的加权互动率 35 分 + 按预计 24h 浏览与置信度计的破圈 20 分 | 三项分别对应热门池、排序权重、OON 折扣，避免几十浏览拿满分       |
| 互动率             | 自定权重                                    | 点赞 0.708、回复 5、转发 1、引用 5                                                         | `home-mixer/params/param.rs` 最新排序权重                        |
| 回复机会的剩余浏览 | 线性外推                                    | 按衰减模型积分                                                                             | 同上                                                             |
| 冷启动识别         | 仅看粉丝 / 年龄 / 浏览                      | 排除回复与转发；主页悬停提示按 `coldStartFollowerCap = 5万` 判定                           | `author_cold_start.rs` 只扶持原帖/引用，不扶持回复与转发         |
| 主页洞察成熟判定   | 只按「当前时间 − 发帖时间」                 | 结合最后观测时刻 `updatedAt` 算观测时年龄                                                  | 防止久未刷新的早期草稿/新帖被当成「24 小时成熟帖」拉低基线       |
| 新增               | —                                           | 预计 24h 浏览、冷启动试水提示                                                              | 热门池公式、冷启动规则                                           |

参数都在 `packages/metrics/src/config.ts`，注释里写了对应的 X 源码位置。

## 3. 展示规范

- **推文上不出现汉字**：只用 Lucide 图标、数字和英文缩写。数字一律英文紧凑写法（`164/h`、`32.9K`）。
- **颜色三档，越热越醒目**：平稳只是绿字（`#00a36c`），≥ 1000/h 红字加浅红底（`#F4212E`），≥ 1 万/h 实心红底，火焰图标轻微跳动（系统开启「减少动态效果」时不动）。只有流速会出现底色。
- **量级是一段灰色元数据** `· ☆ 12.8K`，接在 @handle 那一行后面。六档只靠图标区分：嫩芽、闪光、星、奖章、宝石、皇冠（Lucide），不上色、不加底色。配色规则见 [04](04-弹窗与推文徽章重构.md) 第 5 节。
- **量级用英文缩写**：`GLOW` < 100、`SPROUT` 100–1K、`RISING` 1K–5K、`SPARK` 5K–1万、`POPULAR` 1万–3万、`CREATOR` 3万–10万、`KNOWN` 10万–30万、`INFLUENTIAL` 30万–100万、`MACRO` 100万–500万、`MEGA` ≥ 500万。中文名（微光 / 新芽 / 新锐 / 星火 / 人气 / 达人 / 知名 / 影响力 / 头部 / 顶流）只出现在悬停卡片里。
- **解释全部放在悬停卡片里**，跟随界面语言，文案集中在 `apps/extension/src/lib/insight/copy.ts`。

## 4. 从用户需求看，接下来怎么做更好

用户分两类，要的东西不一样：

| 用户                 | 真正的问题                                   | 我们给什么                                                     |
| -------------------- | -------------------------------------------- | -------------------------------------------------------------- |
| 读者（大多数）       | 这条值不值得看？这个人靠不靠谱？             | 流速颜色一眼判断；量级 + 关注比 + 可疑标记；过滤垃圾和 AI 回复 |
| 创作者（付费意愿高） | 我该去哪互动？我的帖子在涨吗？我什么时候发？ | 回复机会；**自己帖子的实时诊断**；最佳发帖时段                 |

按价值排序的下一步：

1. **自己帖子的诊断**（建议优先）。打开自己的帖子时，悬停卡片换成创作者视角：现在处在冷启动试水期吗、预计 24h 浏览、离进入全站热门池还差多少、和自己历史中位数比是好是差。这是 X 原生分析页给不了、竞品也没做的。
2. **回复机会做成页面提示**。现在只在弹窗热帖页里。可以在流速胶囊旁对「回复机会高」的帖子加一个小标记，直接在时间线上提示「这里值得回复」。
3. **按 X 权重提示创作方向**。X 最看重回复、引用、私信/复制链接分享。发布台的 AI 审稿可以据此检查：结尾有没有引导讨论的问题、内容适不适合被转发到私信。
4. **单用户洞察**（P1）照原计划推进，洞察里的爆款判断统一用「预计 24h 浏览」。
