## 1. X 现在怎么排 For You

**打分**：Phoenix（基于 Grok 的 transformer）预测「这个用户对这条帖子做各种动作的概率」，再加权求和：

```text
分数 = Σ 权重 × P(动作)
```

权重（`home-mixer/params/param.rs`）：

| 动作         | 权重                    | 动作     | 权重  |
| ------------ | ----------------------- | -------- | ----- |
| 复制链接分享 | 20                      | 点赞     | 0.66  |
| 回复         | 5（互关的人回复再 +15） | 点击     | 0.3   |
| 引用         | 5                       | 打开链接 | 0.2   |
| 私信分享     | 5                       | 不感兴趣 | −52.3 |
| 关注作者     | 4                       | 静音作者 | −58.8 |
| 分享         | 2                       | 拉黑作者 | −31.2 |
| 转发         | 1                       | 举报     | −234  |

注意：权重乘的是**预测概率**，不是实际次数。X 在代码注释里专门说明：不能理解成「1 次举报抵 468 个赞」。但相对重要性可以借用：**回复、引用、转发到私信/复制链接，比点赞值钱得多**。

**之后的调整**（`xai-value-model/scoring.rs`、`vm-ranker/params.rs`）：

- 非关注者看到的帖子 ×0.75（OON 折扣）。所以浏览远超粉丝，说明推荐系统在主动分发。
- 同一作者在一屏里的第 2、3 条帖子逐条打折（衰减 0.5，下限 0.25）。
- 超过 48 小时的帖子直接过滤（`MAX_POST_AGE`）。

**两条对创作者最重要的机制**：

1. **全站热门帖子池**（`home-mixer/util/popular_posts.rs`）。每 60 秒刷新一次，按「预计 24 小时浏览」选 500 条（每个作者最多 5 条），作为非关注者的候选来源。公式：
   ```text
   λ = ln2 / 8h
   预计 24h 浏览 = 当前浏览 × (1 − e^(−24λ)) / (1 − e^(−λ·max(帖子年龄, 0.5h)))
   ```
   这是 X 自己对「爆款」的定义。
2. **冷启动扶持**（`home-mixer/scorers/author_cold_start.rs`）。粉丝 ≤ 5 万的作者，发出 2 小时内、曝光不足 200 的帖子，会被插进少量推荐位试水。

## 2. 我们据此做的调整

| 项                 | 之前                                        | 现在                                                           | 依据                                                |
| ------------------ | ------------------------------------------- | -------------------------------------------------------------- | --------------------------------------------------- |
| 流速               | 总浏览 ÷ 帖子年龄（全程平均）               | 衰减模型推算「此刻」的速度；有两次观测时用实际增量             | 热门帖子池的 8 小时半衰期模型。全程平均会高估老帖子 |
| 流速有效期         | 72 小时                                     | 48 小时                                                        | X 不推荐 48 小时以上的帖子                          |
| 爆帖指数           | 流速 + 互动率 + 转赞比 + 藏赞比（照搬竞品） | 预计 24h 浏览 45 分 + 按 X 权重加权的互动率 35 分 + 破圈 20 分 | 三项分别对应热门池、排序权重、OON 折扣              |

| 新增               | —                                           | 预计 24h 浏览、冷启动试水提示                                  | 热门池公式、冷启动规则                              |

## 3. 展示规范

- **推文上不出现汉字**：只用 Lucide 图标、数字和英文缩写。数字一律英文紧凑写法（`164/h`、`32.9K`）。
- **颜色三档，越热越醒目**：平稳只是绿字（`#00a36c`），≥ 1000/h 红字加浅红底（`#F4212E`），≥ 1 万/h 实心红底，火焰图标轻微跳动（系统开启「减少动态效果」时不动）。只有流速会出现底色。
- **量级是一段灰色元数据** `· ☆ 12.8K`，接在 @handle 那一行后面。六档只靠图标区分：嫩芽、闪光、星、奖章、宝石、皇冠（Lucide），不上色、不加底色。配色规则见 [04](04-弹窗与推文徽章重构.md) 第 5 节。
- **量级用英文缩写**：`GLOW` < 100、`SPROUT` 100–1K、`RISING` 1K–5K、`SPARK` 5K–1万、`POPULAR` 1万–3万、`CREATOR` 3万–10万、`KNOWN` 10万–30万、`INFLUENTIAL` 30万–100万、`MACRO` 100万–500万、`MEGA` ≥ 500万。中文名（微光 / 新芽 / 新锐 / 星火 / 人气 / 达人 / 知名 / 影响力 / 头部 / 顶流）只出现在悬停卡片里。
- **解释全部放在悬停卡片里**，跟随界面语言，文案集中在 `apps/extension/src/lib/insight/copy.ts`。

## 4. 从用户需求看，接下来怎么做更好

用户分两类，要的东西不一样：

| 用户                 | 真正的问题                                   | 我们给什么                                                     |
| -------------------- | -------------------------------------------- | -------------------------------------------------------------- |
| 读者（大多数）       | 这条值不值得看？这个人靠不靠谱？             | 流速颜色一眼判断；量级 + 关注比 + 可疑标记；过滤垃圾和 AI 回复 |
| 创作者（付费意愿高） | 我该去哪互动？我的帖子在涨吗？我什么时候发？ | 回复机会；**自己帖子的实时诊断**；最佳发帖时段                 |

按价值排序的下一步：

1. **自己帖子的诊断**（建议优先）。打开自己的帖子时，悬停卡片换成创作者视角：现在处在冷启动试水期吗、预计 24h 浏览、离进入全站热门池还差多少、和自己历史中位数比是好是差。这是 X 原生分析页给不了、竞品也没做的。
2. **回复机会做成页面提示**。现在只在弹窗热帖页里。可以在流速胶囊旁对「回复机会高」的帖子加一个小标记，直接在时间线上提示「这里值得回复」。
3. **按 X 权重提示创作方向**。X 最看重回复、引用、私信/复制链接分享。发布台的 AI 审稿可以据此检查：结尾有没有引导讨论的问题、内容适不适合被转发到私信。
4. **单用户洞察**（P1）照原计划推进，洞察里的爆款判断统一用「预计 24h 浏览」。
