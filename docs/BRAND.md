# 福滤娃 Brand Voice

## 品牌人格

福滤娃不是“安全卫士”，也不是严肃的内容审核员。

它更像一个常年混迹 X 垃圾区、什么话术都见过的赛博清洁工。

关键词：

- 懂梗
- 嘴有点损
- 反应快
- 不说教
- 不装正义
- 永远站在“保护用户注意力”这一边

## 核心口号

**福滤娃：不信你看。看不见就对了。**

辅助：

**没有人比福滤娃更懂过滤。**

## 经典话术

> 应该没人比我滤得更开了吧。

> 我的福滤娃不黑，不信你看。

> 看不见？

> 那就对了，刚滤了。

> 福滤娃 FeedSieve，专治 X 机器人发疯。

## 产品文案

| 场景 | 文案 |
| --- | --- |
| 扫描 | 正在鉴定这条推文的成分 |
| 垃圾 | 这条味儿不对，抬走 |
| 已隐藏 | 已滤，别看了 |
| 恢复前 | 你非看不可？ |
| 恢复 | 我偏要看 |
| 白名单 | 自己人，别开枪 |
| 黑名单 | 下次见一次抬一次 |
| 误判 | 这条还能抢救 |
| 无垃圾 | 今天的 X 居然挺像人 |
| 统计 | 今日替你遭罪 38 条 |

## 分享卡片

标题：

**福滤娃今日战绩**

主体可以随机变化：

- 替你看了 428 条推文
- 抬走机器人 31 个
- 过滤复制怪 22 条
- 请走色情引流 18 条
- 送走币圈老师 7 位

底部梗：

- 我的眼睛脏了，你的没有。
- 互联网今天也没有完全失控。
- 今天又替你少生了几次气。
- 看不见就对了。
- 赛博垃圾，日产日清。

## 文案边界

不要把福滤娃写成一个“审查员”。

避免：

- “不允许你看”
- “这条内容不正确”
- “系统判定该观点有害”

优先：

- “像垃圾”
- “命中你的过滤规则”
- “疑似复制怪”
- “根据你的设置先抬走”
- “你非看不可？”

FeedSieve 过滤的是垃圾模式与用户主动定义的低价值内容，不替用户判断观点。
