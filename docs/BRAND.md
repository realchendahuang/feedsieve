# 福滤娃 Brand Voice

## 品牌人格

福滤娃不是“安全卫士”，也不是严肃的内容审核员。

它更像一个常年混迹 X 垃圾区、什么话术都见过的赛博清洁工。

关键词：

- 懂梗
- 嘴有点损
- 反应快
- 不说教
- 不装正义
- 永远站在“保护用户注意力”这一边

## 核心口号

**福滤娃：不信你看。看不见就对了。**

辅助：

**没有人比福滤娃更懂清理。**

## 经典话术

> 应该没人比我滤得更开了吧。

> 我的福滤娃不黑，不信你看。

> 看不见？

> 那就对了，刚送走。

> 福滤娃 FeedSieve，专治 X 机器人发疯。

## 产品文案

| 场景 | 文案 |
| --- | --- |
| 扫描 | 正在鉴定这条推文的成分 |
| 标注 | 这个号味儿不对，框起来 |
| 黄框标签 | 疑似垃圾：名单命中 |
| 一键拉黑 | 送走 N 个 |
| 拉黑成功 | 已送走，全端清净 |
| 撤销误伤 | 拉错了？放回来 |
| 误判反馈 | 这条还能抢救 |
| 待拉黑列表空 | 今天的 X 居然挺像人 |
| 统计 | 今日替你送走 38 个垃圾号 |

## 分享卡片

标题：

**福滤娃今日战绩**

主体可以随机变化：

- 替你看了 428 条推文
- 标注垃圾号 45 个
- 送走机器人 31 个
- 请走色情引流 18 条
- 送走币圈老师 7 位

底部梗：

- 我的眼睛脏了，你的没有。
- 互联网今天也没有完全失控。
- 今天又替你少生了几次气。
- 看不见就对了。
- 赛博垃圾，日产日清。

## 文案边界

不要把福滤娃写成一个“审查员”。

避免：

- “不允许你看”
- “这条内容不正确”
- “系统判定该观点有害”

优先：

- “像垃圾”
- “命中公开名单”
- “疑似复制怪”
- “这个号味儿不对”
- “拉错了？放回来”

FeedSieve 清理的是垃圾账号与用户确认的目标，不替用户判断观点。
