## 安装

| 方式 | 步骤 |
| --- | --- |
| **Chrome 应用商店（推荐）** | 前往[商店页面](https://chromewebstore.google.com/detail/feedsieve/amhdjglnonjaoenddnifpnljgmocfdph)点「添加至 Chrome」，自动接收更新 |
| **GitHub Releases** | 从 [Releases](https://github.com/realchendahuang/feedsieve/releases) 下载 `feedsieve-*-chrome.zip` 解压 → `chrome://extensions` 开「开发者模式」→「加载已解压的扩展程序」 |
| **从源码构建** | `pnpm install && pnpm build:extension`，加载 `apps/extension/.output/chrome-mv3`（Node ≥ 22，pnpm） |

Edge / Brave 等 Chromium 浏览器可用后两种方式加载。装好即用，无需注册任何账号。

## 上手四步

1. **刷 X，看黄框** — 打开 [x.com](https://x.com) 正常滚动。高置信垃圾账号被**黄框**标出，下方一行显示判定的证据来源，内容本身不隐藏。
2. **单个送走** — 黄框上点「顺手拉黑」：走你已登录 X 会话的内部 Block 接口，与手动点屏蔽同一条请求，手机端即刻同步消失。
3. **攒一批一起送走** — 黄标账号自动进**待拉黑列表**（持久，可增删）。点弹窗里的「一键拉黑 N 个」逐个执行：成功即移除，失败如实保留并显示原因（额度用尽 / 限流 / 官方暂停分开提示）。
4. **漏网的自己补** — 在任意推文操作栏或扩展弹窗点「标记垃圾并拉黑」。不需要先理解任何检测规则，你的动作本身就是最高质量的判断。

**误伤了？** 已拉黑列表里点「放回来」一键撤销；页面上点「误标？」把账号加入本地白名单。误标不会进入社区批量候选——社区名单要求至少 3 个独立账号各投一票才生效。

识别的判断分层（用户动作 > 社区名单 > 本地弱证据）与数据流向的完整描述，见 [`ARCHITECTURE.md`](ARCHITECTURE.md)。

## 打野排位

弹窗新增「打野」一级 tab，把清理过程变成公开排位：

- **战报**：本周击杀、命中率、子弹余量、百分位与称号徽章。
- **榜单速览**：弹窗内直接看 Top 10 与你自己的排位（始终置底显示）。
- **完整周榜**：公开网页，纯观看，[feedsieve.win/leaderboard](https://feedsieve.win/leaderboard)。
- **想露脸？** 上榜默认匿名；在弹窗「我的」页认领档案并完成邮箱验证才参与公开署名，可自愿绑定 @handle。

计分口径：**确认击杀 +1**（账号收敛为共识黑名单成员且你当前仍投拉黑票时结算）、**首杀 +1**（同一赛季内最早上报者）、**误伤 −2**（票项被翻案或转入维护者白名单）。按共识击杀而非拉黑数量计分，刻意防止误拉黑刷分。周赛季 ISO 周结算，Top 3 且命中率 ≥80%、开火 ≥10 发获永久称号「猎黄人」。完整规则见 [`HUNTING.md`](HUNTING.md)。

## 设置项逐条

- **同步关注列表** — 把你的关注存为本地私有保护名单，自动排除在一切清理之外，永不上传社区。这是误伤治理的第一道保险。
- **关键词规则** — 官方行业词库包（当前 8 组 778 条，以[官网词库 Tab](https://feedsieve.win/lists#keywords)实时计数为准），默认只开启「黄推 / 成人引流」，其余按需订阅，可整包或逐条关闭，也支持添加自己的词。收录边界与来源见 [`research/KEYWORD_PRESETS.md`](research/KEYWORD_PRESETS.md)；官方词库全量公示在[官网词库 Tab](https://feedsieve.win/lists#keywords)，与扩展执行的规则同源同版本。
- **识别强度** — 清爽 / 标准 / 大扫除 三档。档位只调"用多少证据"，不调"下手多重"：黄框标注在任何档位都永不自动批量拉黑，弱证据只在「大扫除」档提示人工复核。悬停设置项可看各档证据范围。
- **备份与迁移** — 导出 JSON，在新设备预览后合并或替换。导出不含任何 X 登录态，凭据只在你浏览器里。
- **个人白名单** — 页面点「误标？」加入的账号优先级最高，一票否决一切检测来源。

## 批量拉黑的安全边界

FeedSieve 走的是你已登录会话的内部 Block 接口，与手动点屏蔽是同一条请求。X 不公布每日上限，社区实测约每天 400–500 个之后容易被要求验证或强制登出。因此：

- 队列内置 **400 条 / 24 小时**滚动额度，额度用尽自动暂停并提示；点「仍要继续」可放行本轮，但连续硬打会把临时锁定拖长。
- 连续 429 触发**风暴降级**：暂停 + 预算砍半；认证失效当天额度清零，随后逐日恢复。
- 成功间隔按注入节奏加抖动，不做固定节拍的机械请求。
- 大名单先入队，让队列分几天跑完，不要指望一个晚上清零。

机制细节见 [`BLOCK_SAFETY.md`](BLOCK_SAFETY.md)。

## 常见问题

**为什么是拉黑，而不是隐藏？**
本地隐藏只骗过你这一个浏览器；X 原生 Block 全端生效，被拉黑的号永远无法再回复 / @ / 关注你。这是 FeedSieve 与同类工具的根本区别，也决定了所有拉黑都必须由你明确触发。

**需要 X 开发者 API 或 OAuth 应用吗？**
不需要。拉黑通过你已登录的 X 会话执行，FeedSieve 服务器碰不到你的 X 账号。

**我的推文会被上传吗？**
不会。推文原文永不出设备，这是硬红线。内容分析走本地指纹哈希；社区上报只含 handle / 分类 / 话术指纹哈希 / 外链域名，无浏览历史。完整口径见 [PRIVACY.md](https://github.com/realchendahuang/feedsieve/blob/main/PRIVACY.md)。

**被误标了怎么办？**
被错误拉黑的账号找 FeedSieve 用户点「放回来」即可；名声受损风险极低。自己账号进入社区候选的，走[官网申请弹窗](https://feedsieve.win/lists#apply)提交申诉，邮箱验证后进维护者复核队列。

**换号了还能被识别吗？**
能，这是 v0.4 主要解决的问题：话术指纹（换号不换模板）、外链域名（≥2 独立安装一致即下发）、换号别名追踪。历史机制见 [`TECHNICAL_SPEC.md`](TECHNICAL_SPEC.md)。

**白名单有几种？**
两种：社区「验证正常」白名单（净抢救票 ≥3，与黑名单镜像，随签名快照下发、一票豁免）与维护者维护的[推荐白名单](https://github.com/realchendahuang/feedsieve/blob/main/community/lists/whitelist.yaml)（人工筛选的知名正常账号与博主）。两者都永不标注。

**支持 Firefox / Safari / 其他平台吗？**
不支持的。产品边界已拍板：只做 X + Chrome 系浏览器，理由见 [`VISION.md`](VISION.md)。
